# ⚽ FOOT LAB — Terrain tactique interactif

Une mini-application de foot à pions, conçue pour **Messie, Charel, Mamady et Yvan**.

## 🎮 Jouer

**Application en ligne :** https://foot-lab-tactique-roy-team4.vercel.app

- Déplace **Y** (Yvan), **M** (Mamady), **C** (Charel) ou **E** (Messie) avec le doigt ou la souris.
- **Le ballon ne se déplace pas directement :** fais toucher le ballon par un pion pour le propulser. Il ralentit et rebondit.
- Passe entre la vue **2D** et la vue **3D**.
- Essaie de marquer face au gardien mobile : compteur et confettis signalent un but.
- Déplace les joueurs pour modifier la tactique ; active la disposition défensive « Si on joue contre eux ».
- Partage le lien et les placements avec les amis depuis l'application.

## 🧩 Formation de départ

| Joueur | Rôle |
| --- | --- |
| **E** — Messie | Attaquant |
| **C** — Charel | Milieu offensif |
| **Y** — Yvan | Défenseur central / sentinelle |
| **M** — Mamady | Défenseur central |

Système initial **2–1–1**, sans gardien dans l'équipe de quatre pions. Le gardien animé est un adversaire dans les cages.

## 🛠️ Code source

Application web statique dans `index.html` (HTML, CSS et JavaScript). Ouvre ce fichier dans un navigateur récent pour tester localement ; aucun compte n'est nécessaire. Sur iPhone, utilise directement le lien en ligne pour bénéficier des gestes tactiles.

**Note :** la mise en ligne Vercel existe déjà. Ce dossier GitHub est une copie du code source ; les nouveaux commits GitHub ne redéploient pas automatiquement Vercel tant qu'une connexion Git n'est pas configurée.
